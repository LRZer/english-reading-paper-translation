# 英文阅读与论文翻译

[English](README.en.md) | 中文

本地运行的阅读、词汇笔记与论文翻译工具。文章和词汇保存在浏览器中；论文 PDF、提取文本和译文保存在浏览器的 IndexedDB 中。服务只监听本机 `127.0.0.1`。

## 启动

需要 Node.js 和 Git LFS。克隆仓库后运行：

```powershell
git lfs install
git lfs pull
npm ci
npm start
```

Windows 上也可以在安装依赖后双击 `启动阅读与翻译.cmd`。浏览器打开 `http://127.0.0.1:4173`。使用同一浏览器和同一地址才能继续读取原有本机数据；直接双击 `index.html` 会使用另一份浏览器存储，且无法使用本机词典与论文解析接口。

## 主要功能

- 文章库和论文库分别管理内容，均支持文件夹。
- 阅读文章时选词、记录中文释义与笔记，并可在原文中为已收录词汇及常见词形划线。
- 阅读页右栏可切换到 AI 助手，针对当前文章连续提问；支持 DeepSeek Flash / V4 Pro、思考开关与思考强度选择，开启思考时可展开查看返回的思考内容。问答在当前页面会话中按文章分别保留。
- 论文左侧使用浏览器内置 PDF 阅读器，右侧显示完整译文；可以同时翻译多篇论文，离开当前论文后结果仍会自动保存。
- DeepSeek 翻译使用独立的文章和论文提示词；在设置中填写 API Key 并测试连接。密钥仅保存在当前浏览器的本机存储中，不写入项目文件或数据备份。
- 可调整阅读背景、字号、行距、页边距和词典字号。
- 词汇页可查看随项目提供的本地朗文词典。大文件由 Git LFS 管理；克隆后运行 `git lfs pull`，否则词典无法加载。也可通过环境变量 `READING_DICTIONARY_DIR` 指定词典目录，该目录须包含 `LDOCE5++ V 1-35.mdx` 和 `LDOCE5++ V 1-35.mdd`。

论文导入支持带文字层的英文 PDF，图片、表格和公式保留在左侧原版 PDF 中；扫描版 PDF 暂不做 OCR。翻译使用从 PDF 提取的正文，提取质量会影响译文。AI 翻译会向 DeepSeek 发送文章或论文提取文本；向文章助手提问时会发送当前文章和本次对话上下文。

## 本机数据与备份

文章、词汇、文件夹和设置保存在浏览器的 localStorage；论文 PDF、提取结果和译文保存在 IndexedDB。项目目录中的 `保留的数据/` 是私人备份，不会提交到 Git。清理浏览器数据会删除这些记录，请在应用中定期导出备份。

## 开发与上传

```powershell
npm test
```

仓库的 `.gitattributes` 将词典 `.mdx`、`.mdd` 文件交给 Git LFS；`git lfs ls-files` 应能列出这两个文件。`node_modules/`、私人备份、日志和 `.env` 文件由 `.gitignore` 排除。此公开仓库包含词典文件；请确认词典的再分发许可。

项目中的 `vendor/pdfjs-dist` 用于 PDF 正文提取；其许可文件保留在该目录中。项目尚未选择开放源代码许可证。
