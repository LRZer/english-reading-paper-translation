# 英文阅读与论文翻译

[English](README.en.md) · [完整使用手册](docs/使用手册.md) · [English user guide](docs/USER_GUIDE.en.md)

一个在本机运行的英文阅读与论文 PDF 翻译工具。把文章、词汇笔记、针对文章的 AI 对话和论文集中在同一界面；论文阅读保留原版 PDF 排版。数据保存在当前浏览器，本机服务只监听 `127.0.0.1`。

![实际运行的文章阅读页：NASA 英文文章、中文译文与词汇栏](docs/images/02-reading.png)

> 截图使用真实的英文资料和论文，拍摄于独立的演示浏览器。资料来源、演示译文和对话的说明见[使用手册末尾](docs/使用手册.md#截图所用资料)。

## 能做什么

| 场景 | 使用方式 |
| --- | --- |
| 精读英文文章 | 在文章库粘贴原文、按文件夹整理；对照译文，给已收录词汇划线。 |
| 积累词汇 | 选中原文后按 **Ctrl+A** 收录词汇，记录中文释义和笔记，按需展开本机朗文词典。 |
| 提问与翻译 | 用 DeepSeek 翻译文章；每篇文章保存独立的 AI 助手对话，可选 Flash / V4 Pro 和思考设置。 |
| 阅读论文 | 导入 PDF 后自动保存；左侧用浏览器原生阅读器查看，右侧翻译正文，支持多篇论文同时翻译。 |

## 本机启动

准备 **Node.js 24.15+**（或 22.22.2+）和 **Git LFS**，然后运行：

```powershell
git clone https://github.com/LRZer/english-reading-paper-translation.git
cd english-reading-paper-translation
git lfs install
git lfs pull
npm ci
npm start
```

在浏览器打开 **http://127.0.0.1:4173**。Windows 上完成依赖安装后，也可以双击 `启动阅读与翻译.cmd` 启动。请保持服务窗口开启。直接双击 `index.html` 无法使用本机词典和论文解析接口，也会访问另一份浏览器存储。

> 项目中的朗文 `.mdx` / `.mdd` 由 Git LFS 管理。如果克隆后词典不可用，先运行 `git lfs pull`，再重启服务。

## 从哪里开始

1. 进入「文章库」→「＋ 添加文章」，填写标题和英文原文。可选填来源、文件夹、中文标题和译文。
2. 打开文章，在原文里选词并按 **Ctrl+A**，在右侧记录中文释义和笔记；需要时打开「朗文词典」。
3. 使用 AI 功能前，到右上角「设置」填写 DeepSeek API Key 并测试连接。文章页「工具」中有 AI 翻译，右栏可切换到 AI 助手。
4. 在「论文库」点击「＋ 添加论文」或拖入 PDF。左侧阅读原版，右侧等待或启动翻译。

## AI、论文与本机数据

- 文章翻译与论文翻译使用不同提示词。文章译文可在保存前检查、修改；论文翻译显示阶段和段落进度。阅读页的助手先展示当前文章的对话列表，可继续旧对话或新建对话。
- 论文导入支持**带文字层的英文 PDF，单篇最大 50 MB**。扫描件暂不做 OCR；图片、表格和公式保留在左侧原版 PDF，右侧重点翻译提取出的正文。提取顺序会影响译文质量。
- 文章、词汇、文件夹与设置保存在浏览器 `localStorage`；论文 PDF、提取结果、译文和助手对话保存在 `IndexedDB`。AI 请求会把相应的文章正文、论文提取文本或对话上下文发送到 DeepSeek。
- DeepSeek API Key 长期保存在**当前浏览器**，不写入项目文件或导出备份。应用 JSON 备份包含文章、词汇和助手对话，**不包含论文 PDF、提取结果及译文**；请另外保留论文原文件。

浏览器或网站地址一变，本机存储也可能不同。请固定使用 `127.0.0.1:4173`，并定期用右上角 **↥** 导出备份。详细说明见[备份与恢复](docs/使用手册.md#6-备份与恢复)。

## 开发与仓库说明

```powershell
npm test
```

`node_modules/`、日志、`.env` 和个人备份不会提交。词典默认位于 `dictionary/ldoce5/`；也可通过 `READING_DICTIONARY_DIR` 指向包含 `LDOCE5++ V 1-35.mdx`、`LDOCE5++ V 1-35.mdd` 的目录。PDF 正文提取所用的 `vendor/pdfjs-dist` 保留了其许可证文件。

此仓库包含朗文词典文件。公开分发前请确认相关词典的再分发许可；项目目前尚未选定开源许可证。
